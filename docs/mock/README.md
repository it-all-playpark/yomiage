# UI モック

- 公開版（クリックで動く）：https://claude.ai/artifact/1eyAARu1FZ4L1iRQBDSUZ1
  - 作成者の Claude アカウントでのみ開けます。ほかの人に見せるときは、Artifact の Share メニューで共有してください
- このフォルダ：上のモックのソース（Claude の Design canvas 形式の `.dc.html`）。実装の参考用で、ビルドには使いません

## 画面

| ファイル | 画面 | 主な内容 |
|---|---|---|
| `Main.dc.html` | 翻訳と読み上げ | 原文／訳文、1 文ずつ受信して読み上げ、語クリックで読みを修正（この文だけ／辞書に登録）、ふりがなをすべて表示、読み上げ中の語のハイライト、直した読みの一覧 |
| `Setup.dc.html` | 初回設定 | Groq API key の登録 3 ステップ、接続テスト、モデル選択、key の扱いの説明 |
| `Dictionary.dc.html` | 読み辞書 | 追加（試聴付き）、一覧・絞り込み・編集・削除、書き出し／読み込み |
| `canvas.json` | キャンバスの配置 | 3 画面の位置と大きさ |
