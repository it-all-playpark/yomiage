はじめに、Groq の API key を登録します

翻訳と読みの付与に Groq を使います。key は一度登録すれば、次からは文章を貼ってボタンを押すだけです。

  1. 1
    Groq に無料で登録する console.groq.com を開く
  2. 2
    API Keys のページで key を作ってコピーする 「gsk_」で始まる文字列です。
  3. 3
    下に貼り付けて「接続をテスト」を押す
接続できました。この key で翻訳できます。
速さ重視は、ボタンを押してから声が出るまでが短くなります。訳の質が気になるときだけ精度重視にしてください。
保存してはじめる

key の扱い

  • key はこのブラウザの中にだけ保存されます。
  • 文章と key は Groq に直接送られます。このアプリの開発者のサーバーは通りません。
  • 料金は登録した Groq アカウントの無料枠の範囲です。上限は Groq の画面で確認できます。
  • 共有のパソコンで使ったときは、終わったら key を削除してください。
