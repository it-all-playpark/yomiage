# 要件定義

## 背景

DeepL の日本語読み上げは漢字の熟語に弱く、1 字ずつ訓読みしてしまう。

| 語 | 正しい読み | DeepL の読み上げ |
|---|---|---|
| 習近平 | しゅうきんぺい | ならきいぺい |
| 皇位継承 | こういけいしょう | すめろぎいけいしょう |
| 健常な人 | けんじょうなひと | けんつねなひと |

DeepL の読み上げには読みを登録する機能がない。VOICEVOX はユーザー辞書があるが、読み込みが遅く体感がもっさりするので使わない。

## 目的

外国語の文章を日本語に訳し、**正しい読みで、待たずに**読み上げる。読みを間違えたら、その場で直せる。

## 利用者と環境

- 利用者：Windows の Microsoft Edge で使う。開発者ではない
- 開発：macOS
- 費用：無料。利用者が自分の Groq アカウント（無料プラン）を登録して、その無料枠の中で使う

## 方針（決定事項）

| 項目 | 決定 | 理由 |
|---|---|---|
| 形態 | サーバーを持たない静的 Web アプリ | 無料で配れる。インストール不要 |
| API key | 利用者が自分の Groq key をブラウザに保存する（BYOK） | 開発者が key を預からないので、管理の手間と漏えいの責任がない |
| 翻訳と読み付け | Groq の LLM をブラウザから直接呼ぶ | 速い。無料枠がある |
| 読み上げ | ブラウザ標準の `speechSynthesis`（Edge の音声） | 無料。待ち時間がない。Groq には日本語の音声合成がない |
| 読みの渡し方 | 読みを直した語だけかなにし、ほかは漢字のまま音声に渡す | 全文かなにするとイントネーションが崩れるため |
| 全語の読みの表示 | ブラウザ内の形態素解析（kuromoji.js）で出す | 無料。トークンを使わない |
| VOICEVOX / DeepL | 使わない | 上記の背景のとおり |

## 機能要件

### FR-1 初回設定（Groq API key）

- FR-1.1 Groq への登録から key の貼り付けまでを 3 ステップで案内する
- FR-1.2 key を入力・表示切り替えできる。「接続をテスト」で key が使えるか確かめられる
- FR-1.3 key はブラウザ（localStorage）にだけ保存する。外部に送るのは Groq の API だけ
- FR-1.4 「このブラウザから key を削除」で key を消せる
- FR-1.5 翻訳に使うモデルを選べる（速さ重視をおすすめにする）
- FR-1.6 key が未登録のときは、翻訳画面からこの画面に誘導する

### FR-2 翻訳

- FR-2.1 原文を貼り付けて「翻訳する」（または Ctrl + Enter）で日本語に訳す
- FR-2.2 原文の言語は自動で判定する。手動でも選べる
- FR-2.3 訳文は 1 文ずつ届き、届いた文から画面に出る

### FR-3 読み上げ

- FR-3.1 1 文目の訳が届いた時点で、自動で読み上げを始める
- FR-3.2 再生・一時停止・最初から読む、ができる
- FR-3.3 声（Edge で使える日本語の音声）と速さを選べる。選んだ値は保存する
- FR-3.4 読み上げ中の語をハイライトする
- FR-3.5 音声に渡す文は、読みを直した語だけかなにし、ほかは漢字のままにする

### FR-4 読みの表示と修正

- FR-4.1 AI が「誤読しやすい」と判断した語に読みを付け、オレンジで示す
- FR-4.2 「ふりがなをすべて表示」で、すべての漢字の語に読みを出せる
- FR-4.3 訳文の漢字の語はすべてクリックでき、クリックすると修正パネルが開く
- FR-4.4 修正パネルでは、今の読みとその出どころ（自動解析・AI・この文だけ・辞書）を示し、読みを書き換えて試聴できる
- FR-4.5 保存先を「この文だけ直す」か「辞書に登録して直す」から選べる。直した語は青で示す
- FR-4.6 「表示用／読み上げ用」を切り替えて、実際に音声に渡す文を確認できる
- FR-4.7 「直した読み」一覧で、AI と自分が直した語を確認し、そこから修正・辞書登録できる

### FR-5 読み辞書

- FR-5.1 単語と読み（ひらがな）を追加できる。追加前に試聴できる
- FR-5.2 一覧・絞り込み・編集・削除ができる
- FR-5.3 辞書の読みは、AI や自動解析の読みより優先する
- FR-5.4 JSON で書き出し・読み込みでき、別の PC に移せる

## 非機能要件

- NFR-1 速さ：「翻訳する」を押してから声が出るまでを短くする。目標は **1.5 秒以内**（目標値。実測して見直す）
- NFR-2 費用：Groq の無料枠の中で、1 日 1 時間程度は使えること
- NFR-3 プライバシー：開発者のサーバーを持たない。原文と key は Groq にだけ送る
- NFR-4 対応ブラウザ：Windows の Microsoft Edge（最新版）を主対象にする。Chrome でも動くこと（声の種類は減ってもよい）
- NFR-5 画面幅：スマホ幅でも崩れない（メニューは縦に並び、横スクロールが出ない）
- NFR-6 アクセシビリティ：キーボードで操作できる。ボタンは 44px 以上。文字のコントラストは 4.5:1 以上

## 対象外

- 利用者アカウント・ログイン・サーバー側の保存
- 音声ファイルの書き出し（`speechSynthesis` では録音できないため）
- VOICEVOX・DeepL との連携
- 日本語以外への翻訳
